# Steps for Windows systems

Allow Windows to show hidden files

Delete Skyrim
* C:\SteamLibrary\steamapps\common\Skyrim Special Edition (or wherever)
* C:\Users\<user>\AppData\Local\Skyrim Special Edition
* C:\Users\<user>\Documents\My Games\Skyrim Special Edition
* C:\Users\<user>\Documents\My Games\Skyrim.INI
* Via Steam delete Skyrim and the Creation Kit

Not needed here, but for most lists I recommend setting up a 40GB Pagefile

Install C++ & .NET
* https://aka.ms/vs/16/release/vc_redist.x64.exe
* https://dotnet.microsoft.com/en-us/download/dotnet/thank-you/runtime-desktop-9.0.11-windows-x64-installer

In Steam, unselect the DLC if you have it (this won't work, but I do it anyway)

Download Skyrim (not in the main drive's 'Program Files')

Disable Overlay, Steam Cloud, and Auto-Updates

Launch Skyrim, quit after it sets your settings, no need to launch the game

Download Creation Kit (same location as Skyrim)

Disable Overlay, and Auto-Updates

Launch Creation Kit, say yes to everything, close the Creation Kit when it's done loading

Download and launch [Wabbajack](https://www.wabbajack.org/)

Sign into your Nexus account in Wabbajack

Install the Modlist from file

After everything is done, consider compressing the Steam install of the game to save space now and save time next time

Add a shortcut to the new MO2 exe

Delete the old Skyrim shortcuts so you don’t accidentally run them

Delete anything in this folder. If you followed the steps above, it should already be empty. This list doesn't need this step, but other lists do, so it's a good habit
* C:\Users\<user>\AppData\Local\Skyrim Special Edition
