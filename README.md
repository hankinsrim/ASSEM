# ASSEM

A near-vanilla Skyrim Special Edition list on 1.7.104, with no Anniversary Edition or Creation Club content. The focus is on being bug-free, with quality-of-life features.

**This list is not ready for public use,** and may never be. This project exists mostly for me to learn how [Wabbajack](https://www.wabbajack.org/) files work.
